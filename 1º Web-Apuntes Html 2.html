LISTAS DESPLEGABLES

Nos faltaba este apartado en la primera parte de Apuntes HTML, aqui se explica:

Para realizar una lista desplegable, usamos las siguientes etiquetas:

  • Label para crear el campo
  • Select crea la lista
  • Option value ponemos las opciones (recordad que el nombre de la opcion debe de ir fuera de las etiquetas!)






    • FORMULARIOS

    Un formulario se crea con las siguientes etiqeutas:

    • Form para crear el propio formulario
    • Action para indica donde se realiza el envio de datos
    • Method indica el envio de datos

    Para entrar luego ya en lo que se encutra dentro del formulariose usaran las siguientes etiquetas

    • Label introudce un campo
    • Input type= "text" para introducir el texto especifico
    • PlaceHolder muestra texto guia
